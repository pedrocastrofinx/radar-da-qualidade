# Radar da Qualidade

Jogos de treinamento para a conversa com o cliente (assinatura de veículos).

- `index.html`: menu com os jogos
- `vou-pensar/`: Operação Fechamento (quiz com narração por voz)
- `memoria/`: Memória sobre rodas

Site estático, sem build. Abra `index.html` no navegador ou publique via GitHub Pages.
